# Análise geoespacial protegida

Página estática com conteúdo criptografado em AES-256-GCM e derivação de chave PBKDF2-SHA256 (600.000 iterações).

O navegador exige login e senha para descriptografar o conteúdo. Credenciais não são incluídas neste repositório. Não há dados geoespaciais nem imagens em texto aberto. O acesso é compartilhado por credencial; não existe gestão de contas ou revogação individual no servidor.
